# Photo drop-off (staging)

Upload new project photos here. Claude will convert (incl. HEIC),
resize/optimize, sort into the real project folders, and add them to
the Projects page — then this folder gets cleared out.

## Fastest workflow
- **Group into subfolders by project** (one folder per building/job),
  e.g. `images/_incoming/maspeth-hq/`, `images/_incoming/dime-bank/`.
  The folder names become the project grouping — no manual sorting needed.
- HEIC is fine — leave them as-is, don't convert first.
- If a batch belongs to a project already on the site, name the folder
  to match (e.g. `st-hildas`, `healthcare-facility`, `supportive-housing`).
- Upload to the **fps-website-build** branch (the live one).
