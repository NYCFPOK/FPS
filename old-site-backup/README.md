# Old Site Backup — fpscontracting.com

This folder holds an archived copy of the **original** live website
(fpscontracting.com), kept for reference in case we ever need the old
content, layout, or assets.

## How to add the backup

The live site is behind Cloudflare bot protection, so it can't be
downloaded automatically. To capture it from your own browser:

1. Install the free **SingleFile** extension
   (Chrome: https://chromewebstore.google.com/detail/singlefile/mpiodijhokgodhhofbcjdecpffjipkle
    Firefox: https://addons.mozilla.org/firefox/addon/single-file/)
2. Open each page of fpscontracting.com:
   - Home
   - About Us
   - Services
   - Projects / Gallery
   - Testimonials
   - (any others)
3. Click the SingleFile icon — it saves the whole page (text + images +
   styles) as one self-contained `.html` file.
4. Drop those `.html` files into this folder (or send them in the chat
   and they'll be committed here for you).

## What's already preserved elsewhere in this repo

Even without the full HTML archive, the substance of the old site is
already captured in the new build:

- **Reference letters** — `docs/*.pdf` (Grand Healthcare, KRG, Sollis,
  Mitropoulos, Vassalotti) and `files/st-hildas-house.pdf`
- **Testimonials** — all client quotes + logos on `testimonials.html`
- **About / Services copy** — carried into `about.html` / `services.html`
- **Project photos** — `images/projects/` and `images/gallery/`
- **Client logos** — `images/logos/`
